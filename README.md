# Raja Thandai — Website

A polished one-page website for **Raja Thandai**, the iconic thandai shop in Chowk, Lucknow, serving since 1936.

## What the site is

A single-page, mobile-friendly website with:

- Hero section with key facts (since 1936, open daily 9:00 AM – 11:00 PM, masala ground fresh daily)
- About section with an Opening Hours card
- Menu Highlights — 6 cards, with no prices listed (visitors are asked to check at the counter for today's prices)
- Photo gallery
- Visit Us section with address, phone, hours and a Google Maps directions link
- Enquiry form that opens WhatsApp with a prefilled message

All copy is in clean professional English. Theme: rich maroon with saffron / gold accents.
